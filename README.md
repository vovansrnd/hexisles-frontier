# HexIsles: Frontier

Шестигранная стратегия с экспедицией на неизведанные земли: туман войны, мод
«Скверна» с фракциями Культ/Орден, обучаемые боты и локальный сервер.

## Быстрый старт

```bash
./run_local_v5.sh            # http://localhost:8080 — один порт для клиента и WebSocket
```

Лобби по умолчанию: 12 очков для победы, туман войны, Скверна «Культ ↔ Орден»,
открытая сторона, интенсивность 40%, мягкий разбойник, сложность «Скайнет»,
боты C3PO / R2D2 / T-800 (архетипы «стратег», «торговец», «агрессор»).

## Что внутри

| Файл | Назначение |
|---|---|
| `isles_core.py` | Игровое ядро: карта, фазы, действия, торговля, рейдер |
| `mods_pack.py` | Мод «Скверна» (режимы environmental / tactical / factions) + торговые маршруты |
| `ai_brain.py` | Оценочный бот: одна шкала действий, цели через сеть дорог, эндгейм, туман |
| `server_local_v4.py` | Локальный сервер (клиент + WebSocket на одном порту) |
| `static_v5/` | Клиент v5 (карта на весь экран) |
| `match_archive.py` | Архив завершённых партий (SQLite) |
| `tests/` | Тесты ядра, мода и серверных маршрутов |
| `docs/` | Дизайн-документ, контракты режимов Скверны, методика плейтеста |

## Мод «Скверна»

- Распространение по продуктивным секторам с настроенной вероятностью (шанс настраивается).
- Режим **factions**: динамическое выравнивание Культ/Орден, слёзы за добычу на заражённых
  секторах (Культ), благословения за очистку (Орден), две дорожки прогресса до +3 ОП,
  обличение в скрытом режиме.
- Очистка защищает сектор от нового заражения; осквернение недоступно по своим постройкам.
- Подробные контракты режимов: `docs/blight_mode_contracts.md`.

## Боты

`BotBrain` оценивает легальные действия одной шкалой (поселения/города/дороги/хартии/
торговля/модовые действия), планирует достижимые поселения через сеть дорог и учитывает
эндгейм. Персонажи задаются профилями `Personality` + `StrategyGenome` (жадность, риск,
агрессия, экспансия, любовь к хартиям и торговле, любопытство к туману).

## Лаборатория диагностики (`tools/`)

| Инструмент | Назначение |
|---|---|
| `tools/ai_debugger.py` | Трассировщик: каждое решение бота (оценка, причина, топ-кандидаты, цель), журнал, телеметрия Скверны → `trace.jsonl` / `transcript.txt` / `summary.json` |
| `tools/play_session.py` | Драйвер headless-партий: все боты (`--auto`) или человек-в-контуре (файловый протокол `turn.json`/`decision.json`, планы действий, любое место человека `--human-seat`) |
| `tools/view_turn.py` | «Кибитер»: разбор текущего хода игрока — ресурсы, сторона, видимая Скверна, топ вершин расстановки (геометрия сверена с движком) |
| `tools/verify_geometry.py` | Сверка реконструкции смежности с движком (туман учтён как норма видимости) |
| `tools/summarize_sessions.py` | Сводка по сериям партий: победы, ОП, мод-ОП, стороны |

```bash
python3 tools/play_session.py --auto --seed 1 --out sessions/game1   # боты сами
python3 tools/play_session.py --me "Имя" --human-seat 1 --out sessions/my1  # человеком играете вы
python3 tools/view_turn.py sessions/my1                              # разбор текущего хода
```

Честность информации: человек видит только то, что движок отдаёт его месту
(туман фильтруется движком); внутренние данные движка пишутся лишь в отладочные артефакты.

## Ветки и версии

- `main` — игровое ядро (v1.0.0) + лаборатория диагностики (v2.0.0) + отчёт аудита решений
  ИИ (`docs/audit-report.md`).
- `experiment/cult-price` — изолированный эксперимент: условная цена выхода из Культа
  при очищении (runtime-обёртка над скорером, симуляции A0–A3, разборы случаев).
- Теги: `v1.0.0` — ядро, `v2.0.0` — лаборатория диагностики.

## Аудит решений ИИ

`docs/audit-report.md` — полный отчёт: геометрия реконструкции сверена с движком,
трассы решений с оценками и альтернативами, разбор очищений культистами и
размещения поселений с учётом Скверны, изолированный A/B-эксперимент условной
цены выхода из Культа (A0–A3, 1200 партий на парных сидах) со статистикой.
