# Эксперимент: условная цена выхода из Культа при очищении

Изолированный лабораторный эксперимент. Игровые файлы (`mods_pack.py`, `ai_brain.py`,
движок) не изменяются — цена реализуется runtime-обёрткой над `BlightMod.score_ai_action`
внутри воркера симуляции (`tools/sim_cult_price_experiment.py`).

## Дизайн

- Руки: A0 (без цены), A1 (цена только при выходе: score_after ≤ 0), A2 (выход + умеренная
  при score_after = 1), A3 (сильнее в обоих случаях).
- Коэффициенты из измеренных порогов трасс (медианы зазоров «отказ от очищения»):
  P_exit = 1.3; P_step(A2) = 0.7; A3: 1.5 / 1.4. Не подбирались под желаемое число выходов.
- 300 парных сидов × 4 руки = 1200 партий, дефолтная конфигурация лобби (12 очков, туман,
  factions, open, 40%, скайнет), состав ботов детерминированно перемешивается per seed.

## Результаты (300 парных сидов на руку)

| Рука | Выходов из Культа | Очищений | Слёз | мод-ОП | Смен победителя |
|---|---|---|---|---|---|
| A0 | 139 (0.463/п) | 9316 | 4476 | 2556 | — |
| A1 | 112 (0.373/п) | 9315 | 4702 | 2581 | 20/300 |
| A2 | 99 (0.330/п) | 9098 | 4700 | 2553 | 33/300 |
| A3 | 76 (0.253/п) | 8994 | 4627 | 2571 | 55/300 |

Парные CI (бутстрап по сидам): переходы cult→не-cult значимы и монотонны во всех руках
(A1 −0.09, CI (−0.133, −0.05)); уникальные вышедшие игроки и финал вне Культа — значимы;
слёзы значимо растут в A1/A2 (в A3 — не значимо: подавление компенсирует иммунитетный
прирост); мод-ОП — значимых изменений нет; доли побед по архетипам — все CI включают ноль.

Вывод (узкая формулировка): небольшая условная цена уменьшает выходы из Культа по всем
трём метрикам, почти не сокращает очищения (9315 против 9316 в A1), прирост слёз —
иммунитетный. Об улучшении баланса или «интеллекта» не заявляется.

## Разборы случаев

- `tools/analyze_cult_cleanses.py` — все очищения культистами: потеря выравнивания,
  восстановленная добыча, платёж, лучшая альтернатива, траектории игроков.
- `tools/analyze_settlements.py`, `tools/sensitivity_settlements_local.py` — размещение
  поселений с учётом Скверны: локальная предельная ценность ресурса в шкале скорера,
  перевороты выбора, три перспективы (нейтрал/культ/орден) для стартовых размещений.
- `tools/sensitivity_cult_price.py` — пороги «перецеливания» и «отказа от очищения»
  по каждому случаю.
- `tools/audit_blight.py` — майнер сомнительных решений по Скверне из трасс.

## Запуск

```bash
python3 tools/sim_cult_price_experiment.py --games 300 --seed-start 50001 --workers 10
python3 tools/analyze_cult_price_stats.py
python3 tools/analyze_cult_cleanses.py "sessions/audit2_s*/trace.jsonl"
python3 tools/analyze_settlements.py
```

Смешанные партии с человеком: `tools/play_session.py --me "Имя" --human-seat 1
--cult-price "1.3,0" --out sessions/mixed_a1`.
