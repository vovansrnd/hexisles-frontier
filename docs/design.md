# Визуальный язык «Terra Incognita»

**Идея.** Игра — это экспедиция по неизведанным землям, а экран — стол картографа. Карта главная, всё остальное — инструменты вокруг неё. Используется только тёмная тема: «ночь, лампа, чертёжный стол». Цвета интерфейса заданы переменными в `css/theme.css`; переключателя светлой темы нет.

## Принципы
1. **Карта — героиня.** Территория, жетоны и фигуры читаются с первого взгляда; панели — тёмные/бумажные «подложки» без декора.
2. **Один акцент.** Латунь (`--brass`) означает «это можно/нужно сделать сейчас»: пульсирующие кольца целей, кнопка «Бросить»/«Конец хода», рамка вашего хода.
3. **Неизвестность видна.** Туман — штрихованный сектор со знаком «?»; при открытии сектор вспыхивает. Скверна — фиолетовая крапчатость с кольцом (стадия 2 — «бегущий» пунктир).
4. **Не только цвет.** Игроки различаются цветом, но включаемые «значки игроков» (круг/квадрат/ромб/треугольник) дублируют цвет на фигурах и аватарах. Ресурсы всегда с иконкой и подписью.
5. **Подсказка вместо ошибки.** Недоступные кнопки объясняют причину в подсказке («Не хватает ресурсов», «Нет подходящего места»), нехватающий ресурс в цене подсвечен красным.

## Палитра (тёмная тема)
| роль | цвет |
|---|---|
| фон / панель | `#0b1016` / `#151e29` |
| текст / приглушённый | `#ebe5d3` / `#8393a5` |
| акцент | `#dca94b` |
| океан | `#1b2e40 → #0a1118` |
Территории: лес `#3d7a4d`, холмы `#b4603f`, поля `#d4b64d`, пастбища `#8dbd62`, горы `#77828f`, пустошь `#a89a80`, руины `#7d6b96`. Жетоны 6 и 8 — красные, остальные чернила на «монете».

## Типографика
Без внешних шрифтов (работает офлайн): заголовки и числа очков — `Iowan Old Style / Palatino / Georgia`, интерфейс — системный `system-ui`, цифры везде табличные (`font-variant-numeric: tabular-nums`).

## Графика
Всё — встроенный SVG: символы ресурсов, эмблемы территорий, постройки, рейдер, иконки интерфейса (`js/glyphs.js`). Нет файлов изображений, нет внешних запросов; графика остаётся чёткой при любом масштабе.

## Движение
Короткое и осмысленное: бросок кубиков (кувырок), «вылет» новой постройки, прорисовка тракта, вспышка открываемого сектора, всплывающие «+2 / −3» над картами ресурсов, подсветка секторов, давших ресурсы. Отключается переключателем «Анимации» и системной настройкой `prefers-reduced-motion`.

## Адаптивность
* ≥1180 px — три колонки: игроки · карта · журнал/обмен/патенты.
* 820–1180 px — журнал уезжает в выдвижную панель.
* <820 px — игроки полосой сверху, карта на весь экран, нижняя панель рук и действий; щипок и перетаскивание на карте.
* Панель действий сама переходит из одной строки в две по ширине сцены (container query).
